# Gamedev

Unity medieval castle and town project.

## Open the project

1. Install Git LFS and run `git lfs install`.
2. Clone this repository and run `git lfs pull`.
3. Add the repository folder in Unity Hub and open it with Unity **6000.5.8f1**.
4. Open `Assets/Scenes/MyForest.unity`.

Unity regenerates the Library and other editor caches on first open. Assets, metadata, Packages, and ProjectSettings are included. Local scene backups and temporary editor action requests are excluded.
